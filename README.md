# 🌟 MYVAULT  

**MYVAULT** is a web application built with **PHP, HTML, CSS, and JavaScript** that helps you store and organize your favorite things — movies, books, games, music, and anything else you love.  
The main goal: **never forget what you like.**  

🎥 [Watch Demo on YouTube](https://youtu.be/CJxpx3u26bM)  

[![Demo](https://img.youtube.com/vi/CJxpx3u26bM/0.jpg)](https://youtu.be/CJxpx3u26bM)  

---

## 🚀 Features  
- 📌 Add and manage your favorite things (movies, books, music, notes, etc.)  
- 🔍 Quick search and sorting  
- 🎨 Clean and minimalist interface  
- 🛡️ Secure login and personal dashboard  
- 📱 Responsive design — works well on both desktop and mobile  

---

## 🛠️ Technologies  
- **Backend:** PHP  
- **Frontend:** HTML, CSS, JavaScript  
- **Database:** MySQL  
- **Styling:** Custom CSS + responsive layout
